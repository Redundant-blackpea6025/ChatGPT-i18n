## 💡 What Are Locale Files?

Locale files are simple text files that store all the words and phrases your app displays. For example, if your app has a button that says "Save," that word lives in a locale file. When you translate that file, the button will say "Guardar" in Spanish, "Enregistrer" in French, or "保存" in Japanese – depending on what language the user chooses.

These files usually have extensions like:
- `.json` (common for modern web apps)
- `.yml` or `.yaml` (used in many configuration files)
- `.properties` (common for Java applications)

ChatGPT-i18n understands all these formats and keeps them intact during translation.
